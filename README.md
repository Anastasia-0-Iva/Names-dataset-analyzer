# Names-dataset-analyzer — Профессиональный анализатор популярности имён России

## О проекте
Names-dataset-analyzer — исследовательский инструмент для анализа популярности русских имён, работающий с крупнейшей базой данных popname.ru. Проект включает полный парсинг базы имён (33,249 записей) и предоставляет статистику популярности в реальном времени.

## Возможности
- **Анализ популярности имени** — место в рейтинге и процент носителей
- **Автоматическое определение пола** по окончаниям имён
- **Полная база данных** — 33,249 имён с пагинацией
- **Топ-100 популярных имён** России
- **Интерактивный интерфейс** с обработкой ошибок

## Работа с данными
- **Парсинг с пагинацией** — обработка 332+ страниц с именами
- **Динамическое формирование URL** с учётом пола имени
- **Кэширование данных** — локальное хранение базы имён для быстрого доступа
- **Обработка регистра** — поиск имён без учёта заглавных букв

## Аналитические способности
- **Определение рейтинга** — точное место имени в общем рейтинге
- **Расчёт процента носителей** — статистическая значимость имени
- **Классификация по полу** — автоматическое определение мужских/женских имён
- **Сравнительный анализ** — возможность просмотра топ-100 имён

## Производительность
- 33,249 имён в локальной базе данных
- < 2 секунд на анализ одного имени
- 100% автономность после первоначального парсинга
- Поддержка кириллических символов в URL

## Технологии
- Python 3.8+
- BeautifulSoup4 >= 4.9.0
- requests >= 2.26.0
- pandas >= 1.3.0 (для расширенного анализа)

```
def get_gender(name): #Определяем пол по имени
    endings = ['ь', 'а', 'я']
    if name[-1].lower() in endings:
```
